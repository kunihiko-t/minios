# 位置指定I/O: `lseek` / `pread` / `pwrite`

## 目的

fd APIを完成させる。`read`/`write`がfd保持のoffsetを進めるのに対し、
`pread`/`pwrite`は**offsetを動かさない**位置指定I/O、`lseek`は
offsetをsyscall側から設定する。stateful（fd offset）とstateless
（明示offset）の対比が教育上の要点である。

## ABI

| 番号 | 名前 | 引数 | 意味 |
| ---- | ---- | ---- | ---- |
| 9 | `lseek` | `a0=fd`、`a1=offset(isize)`、`a2=whence` | fdのoffsetを更新し、新しいoffsetを返す |
| 10 | `pread` | `a0=fd`、`a1=buf`、`a2=len`、`a3=offset(u64)` | offsetから読む。fd offsetは不変 |
| 11 | `pwrite` | `a0=fd`、`a1=buf`、`a2=len`、`a3=offset(u64)` | offsetへ書く。fd offsetは不変 |

whence定数: `SEEK_SET=0`、`SEEK_CUR=1`、`SEEK_END=2`。

## 規約

- `lseek`の新offsetは`whence`に応じて `0`/`entry.offset`/`desc.size` +
  `offset`（符号付き）。結果が負または`u64` overflowなら`EINVAL`、
  whence>2も`EINVAL`。file末尾を越えるseekは合法（以後のreadは0、
  writeは`offset>size`を拒否する`write_range`により`EINVAL`）。
- 標準stream fd（0-2）への`lseek`、未割当fdへの3 APIは`EBADF`。
- `pread`はwritable fdへ、`pwrite`はread-only fdへ`EBADF`（方向性は
  `read`/`write`と同じ）。
- `pread`は`read`と同じ検証規約（len≤4KiB、U+W range、`EFAULT`を
  source副作用前に確定）で`ReadComplete`経路を再利用する。
- `pwrite`は`write`と同じ規約（len≤4KiB、U+R copy、`EFAULT`先行）。
- `pread`/`pwrite`/`lseek`はstorageのlazy mountを起こし得るため、
  EFAULT/EINVAL/EBADFは**全て**storageへ触れる前に確定する。
- `pread`/`pwrite`はfd offsetを読みも書きもしない（host testとguest
  双方で証明する）。
- default実装は`ENOSYS`（storageを持たないsourceは無変更）。
- RV32は対象外（process ABIを持たない）。

## 実装

- `abi/src/syscall.rs`: `Lseek=9`、`Pread=10`、`Pwrite=11`、
  `SEEK_SET/CUR/END`、stability test更新。
- `fat32.rs`: `FileDesc::size()` accessor追加（`dir_location`と同じ
  cfg）。
- `syscall.rs`: `ControlSource::{seek_fd,pread_fd,pwrite_fd}` +
  `dispatch_{lseek,pread,pwrite}` + routing。
- `control.rs`: `file_fd_mut`でfd借用→方向性検査→session借用→
  `read_range`/`write_range`へ`offset`をそのまま渡す（`entry.offset`
  を使わない）。`seek_fd`はsession不要（fd tableのみ）。
- `guest/src/bin/file_unlink.rs`と同型の`file_seek.rs`: 下記を順に
  確かめてexit(42)、失敗は70。
  1. `SEEK.TXT`をcreate→"0123456789"write→close→open。
  2. `pread(fd,4,off=4)`→"4567"、直後の`read`→"01"（offset不変の証明）。
  3. `lseek` SET/CUR/END/beyond-EOF/負結果/bad whence/std fd。
  4. `SEEKW.TXT`をcreate→"aaaa"write→`pwrite(off=1,"ZZ")`→
     `write("b")`がfd offset 4へ追記（pwriteがoffsetを動かさない証明）
     →`lseek(0)`→`write("Q")`→close→reopen→"QZZab"照合。
  5. writable fdへの`pread`、read-only fdへの`pwrite`、未割当fd、
     `pwrite(offset>size)`の`EINVAL`。
  6. stdoutへ`seek verified\n`→exit(42)。
- `xtask`: `GUEST_FILE_SEEK`、bundle、`TestKind::FileSeek`、cli filter
  `file-seek`、phase 40、frame列verifier。

## 検証

- host: syscall dispatchの新3経路（fd range、len、EFAULT、EINVAL、
  offset不変、ENOSYS default）。
- QEMU: `cargo xtask test file-seek` + 全40フェーズ。
- RV32 release buildのIMEM適合。
