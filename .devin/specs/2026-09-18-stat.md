# `stat`/`fstat` syscall — file metadataをguestへ

## 目的

guestがfile sizeと種別（file/directory）を取得できるようにする。
typed structをuser memoryへ書き込む初めてのsyscallであり、
`read`のReadComplete copy-out経路を汎用化する。

## ABI

- `Stat = 18`：`a0`=path pointer、`a1`=path length、`a2`=out pointer。
  戻り値は`STAT_LEN`(8)か負のerrno（`read`系のbyte-count規約）。成功時`out`へ8 byteの`Stat`を書く。
- `Fstat = 19`：`a0`=fd、`a1`=out pointer。戻り値は`STAT_LEN`(8)か負のerrno。
- `Stat`（LE、計8 byte）：`size: u32`（file byte数、dirは0）、
  `kind: u32`（`STAT_KIND_FILE = 0`、`STAT_KIND_DIR = 1`）。
- errno：`ENOENT`（不在）、`ENOTDIR`（途中要素がfile）、`EINVAL`
  （path不正）、`EFAULT`（path/out pointer不正）、`EBADF`（fstatの
  fd範囲外・標準stream）、`ENOSYS`（context無し）。

## 意味論

- `stat`は`resolve_path`と同じ規約でfileとdirectory両方を受理する。
  directoryの`size`はFAT32のdir entry sizeに従い0を返す。
- `fstat`はfd tableの`FileDesc`からsizeを返す。directoryはopenでき
  ないためkindは常に`STAT_KIND_FILE`。
- out pointerは`check_user_writable_range`でU+Wを検証し、pathと
  同様にsourceのside effect前にEFAULTを確定する。
- copy-outは`SyscallFlow::ReadComplete`を再利用する：stat bytesを
  `read_scratch[..8]`へ書き、`{start: out, len: 8}`を返せばrun
  loopの`complete_user_read`がSUM付きでuserへcopyする。

## 実装

### ABI / syscall層

- `abi/src/syscall.rs`：`Stat = 18`、`Fstat = 19`、`Stat`構造体
  （`size`/`kind`/`to_le_bytes`）、`STAT_KIND_*`、`STAT_LEN`。
- `ControlSource::stat(path) -> Result<Stat, isize>`と
  `fstat(fd) -> Result<Stat, isize>`（defaultはENOSYS）。
- `dispatch_stat`：path copy → UTF-8 → out EFAULT → source.stat →
  scratchへserializeしてReadComplete。`dispatch_fstat`：fd範囲
  EBADF → out EFAULT → source.fstat → 同じcopy-out。

### storage / control

- `Fat32::stat(path) -> Result<(u32, bool), FatError>`：`resolve_path`
  の`(size, directory)`を返すだけの薄いwrapper。
- `control.rs`：`stat`はstorage sessionへ、`fstat`は`CURRENT_PROC`
  のfd table経由で`FileDesc.size()`。

## 検証

- host：ABI番号・Stat serialize、dispatch（path/out EFAULTがsource
  前、kind/sizeがscratchへ、errno透過、fd範囲EBADF、ENOSYS）、
  Fat32::stat（file size・dir kind・不在・途中file）。
- guest `file_stat`：stat(HELLO.TXT)=file/18、stat(DOCS)=dir、
  stat(DOCS/CHILD.ELF)=file/204、不在ENOENT、途中file ENOTDIR、
  out=0でEFAULT、fstat(open fd)=file/18、fstat(stdout)=EBADF →
  `stat verified` → exit 42。
- QEMU `file-stat` phase（全45）：単一processで確定的、exact frame照合。
- 全45フェーズの`cargo xtask check`。
